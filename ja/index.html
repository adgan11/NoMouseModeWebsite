2 文字入力するだけで、何でもクリック。

スクロール · ⇧⌘J

滑らかなスクロール。どのパネルでも、どこまでも。

矢印キーで、ポインタの下にあるものをトラックパッドでスワイプするように滑らかにスクロールできます。横方向にも対応。Shift を押したままなら一気にスクロールします。

⇧⌘J（オンのときは J）を押すと、スクロールできるすべてのパネルに番号が付きます。ひとつ選んだら、Space で 1 ページ下へ、T でいちばん上へ、B でいちばん下へジャンプ。vim 派なら J K も使えます。

押している間だけ

押している間はオン。離せばオフ。

オン・オフを切り替えたくない場合は、設定で右 Command か右 Option を選んでください。そのキーを押しながらいつものキーで操作し、離せばキーボードは普通のキーボードに戻ります。左側の同じキーは、これまでどおりショートカットに使えます。

シンプルに使いたいなら、⇧⌘M でオン・オフを切り替えられます。このショートカットも変更できます。

No Mouse OFF

マウスで ⌘ キーを押したまま W A S D をタップしてみてください。次は ⌘ を押さずに試してみましょう。

ほかのアプリとも共存

いつものショートカットはそのまま。

⌘、⌃、⌥ を使う操作は、No Mouse Mode がオンのときでもそのままアプリに届きます。S はポインタを動かしますが、⌘S はこれまでどおり保存です。テキストボックスをクリックすると自動的にオフになるので、そのまま入力できます。ターミナルやゲームなどのアプリをリストに追加すれば、それらのアプリでは邪魔をしません。

そのほかの機能

どのアプリでもラベル

アプリの中には、ボタンの位置を macOS に伝えないものもあります。画面上のテキストの読み取りをオンにすれば、Mac 上で動く Apple のテキスト認識を使って、ラベルと入力してクリックがそれらのボタンも見つけ出します。

邪魔をしない

ターミナルやコードエディタ、ゲームを追加しておけば、それらが最前面にある間は自動的にオフになり、離れると再びオンになります。

入力中はオフ

検索ボックスやメッセージ欄をクリックすると No Mouse Mode が身を引くので、次に押すキーはそのまま文字として入力されます。

キーは自由自在

左利きでも、Dvorak や Colemak でも、こだわり派でも。すべてのキーとショートカットを変更でき、ボタンひとつで元に戻せます。

好みのラベル

定番の黄色、黒、白から選べるので、明るいアプリでも暗いアプリでもよく目立ちます。

複数のディスプレイ

画面をまたいで滑らかに移動し、Tab で画面間をジャンプ。ラベルは作業中の画面に表示されます。

ログイン時に起動

メニューバーで静かに起動し、ショートカットを押せばすぐに使えます。

自動アップデート

新しいバージョンは手が空いたタイミングで自動的にインストールされ、作業の途中で邪魔をすることはありません。

Mac にやさしい軽さ

待機中は CPU を使いません。Apple シリコンと Intel の両方に対応したユニバーサルアプリで、macOS 14 以降で動作します。

よくある質問

ほかのキーボードでマウス操作するアプリとどう違いますか？

多くのアプリは、ラベル、グリッド、矢印キーでの移動のどれかひとつだけを提供しています。No Mouse Mode は、クリックラベル、入力してクリック、W A S D による滑らかな移動、ジャンプグリッド、スクロールエリア、保存したスポット、画面間のジャンプまで、すべてをひとつの小さなアプリで実現しています。練習モードも付いているので、その日のうちに使いこなせます。価格は $19.99 の買い切りで、サブスクリプションではありません。

ラベルはどのアプリでも使えますか？

ボタンの情報を macOS に伝えているアプリで使えます。Finder、Safari、Chrome、メール、メモ、システム設定をはじめ、ほとんどの Mac アプリや Web サイトが対応しています。一部のアプリ（特定のゲーム、デザイン用のキャンバス、リモートデスクトップなど）は対応していません。そうしたアプリでは、設定の「Clicking」で Also read text on the screen をオンにしてください。また、ジャンプグリッドと W A S D はどこでも使えます。

画面の読み取りでプライバシーは守られますか？

はい。オンにしない限りオフのままで、Mac 上で動作する Apple のテキスト認識を使い、読み取った内容が保存されたりどこかへ送信されたりすることはありません。macOS ではこの機能が「画面収録」として扱われるため、初回にその権限を求められます。

No Mouse Mode がオンのままでも文字を入力できますか？

どこでも使えるショートカット（⇧⌘Space、⇧⌘/、⇧⌘J）は、オンにしなくても使えます。オンのときに使われるのは No Mouse Mode が使うキーだけで、⌘、⌃、⌥ を使うショートカットはそのままアプリに届きます。テキストボックスをクリックすると自動でオフになるので、そのまま入力できます。常にオフにしておくアプリをリストに登録することもできます。

使いこなすまでにどれくらいかかりますか？

数分です。セットアップの最後に短い実践があり、「Practice」ウインドウには自動でチェックが付く 9 つのレッスンがあります。キーを忘れても、H を押せばいつでもすべてのキーを確認できます。

複数のディスプレイで使えますか？

はい。ポインタは画面をまたいで滑らかに移動し、Tab で次のディスプレイの中央へジャンプします。グリッドは今いる画面で使え、ラベルはウインドウのある画面に表示されます。

キーは変更できますか？

すべてのキーとショートカットを、設定の「Keys」と「General」で変更できます。ボタンひとつで、すべて元に戻せます。

どの Mac で動きますか？

macOS 14 Sonoma、15 Sequoia、26 Tahoe に対応し、Apple シリコン搭載 Mac と Intel 搭載 Mac の両方で動作します。

何台の Mac で使えますか？

標準ライセンスは $19.99 で Mac 1 台分です。それ以上必要な場合は、3 台用（$49.99）、5 台用（$79.99）、20 台用（$299.99）のライセンスがあり、キーひとつですべての Mac に対応します。ライセンスは、設定の「License」→「Deactivate」からいつでも別の Mac に移せます。

バージョン 1 を購入しました。もう一度支払う必要がありますか？
