マウスやトラックパッドなしでMacを使う方法

Macはキーボードだけで操作できます。macOSにはフルキーボードアクセス、マウスキー、音声コントロールが標準で備わっていて、No Mouse Modeのようなアプリを使えば、ラベルを入力するだけでどのボタンでもクリックできます。ここでは、すべての方法とそれぞれの得意分野、そして5分でできるセットアップ手順を紹介します。

2026年10月更新 · 9分で読めます · Ahmed Gagan

結論

まずは標準機能から始めましょう。フルキーボードアクセス（Tabでコントロール間を移動、Spaceで押す）に加えて、メニューバーへはControl-F2、DockへはControl-F3。これで日常的な作業の多くはこなせます。足りないのは、ポインタが必要な操作です。ウェブページ、キャンバス、右クリック、ドラッグなどがそうです。マウスキーはこの穴を無料で埋めてくれますが、オンの間は文字入力ができません。どのボタンも数回のキー入力でクリックし、ポインタもなめらかに動かしたいなら、No Mouse Modeのようなアプリでその両方ができます。

ここで実際に操作できます。動画ではなく、本物どおりに動くNo Mouse Modeの模型です。クリックしてからキーを使ってください。

No Mouse Mode を入手

なぜマウスなしで使うのか？

このページにたどり着く理由は人それぞれです。トラックパッドやマウスが突然壊れて、とにかく今日一日を乗り切りたい。長時間の作業で手首が痛む。あるいは、もともとコードエディタでキーボード中心に作業していて、トラックパッドに手を伸ばすたびに流れが途切れる。うれしいことに、macOSはキーボードユーザーのことを考えて作られていて、足りない部分も簡単に補えます。

今まさにトラックパッドが動かないなら、Macのトラックパッドが動かないときの対処法へどうぞ。快適さが目的なら、手首の痛み対策としてMacをキーボードだけで使う方法をご覧ください。

標準機能：フルキーボードアクセスとキーボードナビゲーション

フルキーボードアクセスは、フォーカスのある項目をハイライトし、ポインタの代わりにキーボードで移動できるようにします。ハイライトの色、コントラスト、サイズを変えられるので、ごちゃごちゃした画面でも見やすくなります。

  1. システム設定 → アクセシビリティ → 運動機能 → キーボードを開きます。
  2. フルキーボードアクセスをオンにします。

使うキー：

  • Tab / ⇧Tab：次または前の要素へ。
  • Space：フォーカスのある項目を選択する、または押す。
  • 矢印キー：グループ内を移動。
  • ⌃Tab / ⌃⇧Tab：次または前の項目へ。
  • Tab-H：コマンドヘルプを開き、そのほかの操作を一覧で確認できます。
  • ⌃⌥⌘P：パススルーモード。これらのキーをアプリ自体が使う場合に。

macOS 14 Sonomaには、システム設定 → キーボードにキーボードナビゲーションというもっと軽い設定もあります。オンにするとTabですべてのコントロールに移動でき、オフにするとTabはテキストボックスとリストの間だけを移動します。⌃F7で両者を切り替えられます。詳しくはフルキーボードアクセスのガイドで解説しています。

弱点：Tabはコントロールを1つずつ順番にたどります。ツールバーの20番目のボタンにたどり着くには何度も押す必要があり、多くのウェブページや独自描画のアプリとは相性がよくありません。

標準機能：フォーカスのショートカット

Tabでは届きにくい画面の各部分へ直接ジャンプできます。一部は、先にシステム設定 → キーボード → キーボードショートカット → キーボードでオンにする必要があります。キーボードによってはFnを加えます（例：Fn-Control-F2）。

標準機能：マウスキー

マウスキーは、キーボードの一部をポインタ操作用に変える機能です。システム設定 → アクセシビリティ → ポインタコントロール → マウスキーでオンにするか、⌥⌘F5を押してアクセシビリティショートカットのパネルを開きます。オンにしたら：

  • 移動：7 8 9 U O J K L（またはテンキー）。
  • クリック：I（テンキーの5）。
  • 押したままにする：M（テンキーの0）、離す：.

ポインティングデバイスがまったくなくても使え、しかも無料です。大きな制限は、Apple自身の説明によると「マウスキーがオンのときは、キーボードやテンキーを使ってテキストを入力できません」という点です。そのため、頻繁にオン・オフを切り替えることになります。オプションの1つで、Optionキーを5回押して切り替えられるようにもできます。No Mouse Mode対マウスキーで直接比べ、キーボードでマウスを動かす方法で詳しく解説しています。

標準機能：音声コントロール

入力するより話したいなら、システム設定 → アクセシビリティ → 音声コントロールをオンにします。「Show numbers」（または「Show names」）と言うと画面上の項目にラベルが付き、「Click」と番号を言うとその項目を押せます。「Show grid」で番号付きのグリッドが画面全体に表示され、「Show window grid」なら最前面のウインドウだけに表示されます。グリッドの番号を言うとズームインします。「Hide numbers」「Hide grid」「Stop listening」で片付けます。

強力で無料ですが、丸一日の作業ですべてのクリックを声で指示するのは時間がかかりますし、共有オフィスでは使いづらいものです。

Controlクリックはどうする？

Appleは右クリックを「副ボタンのクリック（Controlクリック）」と呼んでいます。Controlを押しながらクリックする操作です。ただし、これにも動くマウスかトラックパッドが必要です。一部のAppleキーボードにあるコンテキストメニューキーを含め、キーボードだけで右クリックする方法はマウスなしで右クリックする方法をご覧ください。

No Mouse Mode：何でもクリック、必要なときはポインタ操作

No Mouse Modeは、ここまでに挙げた穴を埋めるメニューバーアプリです。2つの使い方があり、組み合わせて使えます。

クリックラベル（⇧⌘Space）

すべてのボタン、リンク、タブ、メニュー、メニューバー、Dockに短い文字のラベルが付きます。その文字を入力すればクリックされます。最後の文字を入力するときに⇧を押していれば右クリック、⌘ならCommandクリック（ブラウザでは新しいタブ）、⌥ならダブルクリック、⌃ならポインタをそこへ移動するだけになります。Tabを使うと、ラベルが繰り返し表示されて何回も続けてクリックできます。また、ウインドウごとのラベルは毎回同じなので、指が自然に覚えていきます。

入力してクリック（⇧⌘/）

ボタンに書かれている文字の一部を入力し、Returnを押します。大文字・小文字、スペース、アクセント記号は区別されず、頭文字でも探せます。たとえば「nf」でNew Folderが見つかります。

スクロール領域（⇧⌘J）

スクロールできるすべての領域に番号が付きます。1つ選んだら、J/Kまたは矢印キーでスクロール、Spaceで1ページずつ移動、TとBで先頭や末尾へジャンプします。

W A S Dポインタモード（⇧⌘M）

写真の中の一点やスライダーなど、ボタンではないものを操作するときは、No Mouse Modeをオンにします。W A S Dでポインタがなめらかに動き、動き出しは穏やかに加速します。Shiftを押したままにすると高速に、Qを押したままにすると1ピクセル単位の精密な移動になります。Spaceでクリック（2回でダブルクリック、押したままでドラッグ）、Returnで右クリック、Mで中クリック、矢印キーでスクロールします。テキストボックスをクリックすると自動でオフになるので、そのまま入力できます。

ジャンプグリッド（E）

Q W E / A S D / Z X Cのラベルが付いた3×3のグリッドが画面を覆い、押すたびにズームインしていくので、2〜3回のキー入力で画面上のどこにでも届きます。ボタンの情報をmacOSに伝えないアプリも含め、すべてのアプリで使えます。

正直なトレードオフ：ラベルは、アプリがボタンの位置をmacOSに伝えていることが前提です。ほとんどのアプリは対応しています。対応していないアプリでは、オプションの画面上テキスト読み取り（Appleのデバイス上テキスト認識を使用し、画面収録の許可が必要。何も保存・送信されません）をオンにするか、どこでも使えるグリッドとW A S Dを使えます。

ほかのアプリにも、この一部をこなすものがあります。Homerow（2026年10月時点で$49.99の買い切り）とShortcatは、ラベルや検索によるクリックに特化しています。Homerowの前身となった無料のオープンソースアプリVimacは、2022年から更新されていません（Vimacの代替アプリを参照）。まとめはMac向けキーボードマウスアプリのおすすめとHomerowの代替アプリにあります。

5分でできる、マウスなしのMacのセットアップ

  1. フルキーボードアクセスをオンにします。システム設定 → アクセシビリティ → 運動機能 → キーボードで設定します。これでTabとSpaceでほとんどのコントロールに届きます。
  2. ⌃F2と⌃F3を覚えます。それぞれメニューバーとDockに移動します。何も起きない場合は、システム設定 → キーボード → キーボードショートカット → キーボードでオンにします。
  3. 何でもクリックできる手段を加えます。No Mouse Modeをダウンロードし、アプリケーションフォルダにドラッグして開きます。ガイド付きセットアップが、アクセシビリティの許可とライセンスキーの入力を案内します。
  4. ラベルでクリックします。⇧⌘Spaceを押し、クリックしたいものに表示された文字を入力します。
  5. 必要なときはポインタを操作します。⇧⌘Mを押し、W A S Dで移動、Spaceでクリック、Returnで右クリック、Eでグリッドを表示します。
  6. 練習します。メニューバーのアイコンから練習ウインドウを開くと、9つの短い実践レッスンがあります。キーを忘れたらいつでもHを押してください。

途中でつまずいたら、サポートページで許可の設定、ライセンス、すべてのキーを解説しています。

キーボードだけの操作を定着させるコツ

いちばん大変なのは最初の1日です。次の習慣が役立ちます：

  • まずラベルでクリック、ポインタ操作はその次。クリックの大半はボタン、リンク、メニューです。ラベルや入力してクリックなら2〜3回のキー入力で届きます。W A S Dとグリッドはそれ以外のときのために取っておきましょう。
  • 自動でオフにさせる。No Mouse Modeはテキストボックスをクリックすると自動でオフになります。また、ゲームや独自のキー操作を持つコードエディタなど、常にオフにしておくアプリを一覧で指定できます。
  • 押している間だけ使う設定を試す。オン・オフの切り替えを覚えておくのが面倒なら、右Commandか右Optionを押している間だけ動作するように設定できます。
  • よく使う位置を保存する。何度もクリックする位置で⇧と数字を押しておけば、次からは数字だけでそこへジャンプできます。
  • 標準機能も使い続ける。メニューバーへの⌃F2や、Spotlightの⌘Spaceは、ほかの機能と併用してもそのまま使えます。

プライバシーについて：No Mouse Modeはキー入力を保存も送信もしません。オンラインに接続するのは、ライセンスのアクティベートと再確認、アップデートの確認のときだけです。

どれを使うべき？

  • トラックパッドが1日だけ使えない：フルキーボードアクセスとマウスキーで、無料で乗り切れます。
  • 話して操作したい：音声コントロール。
  • 一日中、すべてのアプリをキーボードだけで操作したい：標準機能に加えて、ラベルでクリックでき、ポインタも操作できるアプリ。それこそがNo Mouse Modeの作られた目的です。価格をご覧ください。

Macのどこでも、入力するだけでクリック

No Mouse Modeは、すべてのボタン、リンク、メニュー、Dockアイコンに短いラベルを付けます。必要なときはW A S Dでポインタも動かせます。

よくある質問

Macはキーボードだけで使えますか？

はい。システム設定 → アクセシビリティ → 運動機能 → キーボードでフルキーボードアクセスをオンにすると、Tabでコントロール間を移動し、Spaceで押せるようになります。Control-F2でメニューバーへ、Control-F3でDockへ移動できます。ポインタが必要な操作には、数字キーでポインタを動かすマウスキーを使うか、No Mouse Modeのようなアプリでラベルを入力してボタンをクリックできます。

Macでキーボードを使ってマウスを操作するには？

システム設定 → アクセシビリティ → ポインタコントロールでマウスキーをオンにします。すると7 8 9 U O J K Lでポインタが動き、Iでクリックできます。オンの間は文字を入力できません。No Mouse ModeではW A S Dを使い、なめらかな移動、高速モードと精密モード、Spaceでのクリックが使えます。詳しくはキーボードでマウスを動かす方法をご覧ください。

Macでマウスなしで右クリックするには？

トラックパッドが使えるなら、Controlを押しながらクリックします。キーボードだけの場合、macOSには代替ポインタアクションか音声コントロールがあります。No Mouse Modeでは、Returnでポインタの位置を右クリックでき、ラベルの最後の文字をShiftを押しながら入力するとそのボタンを右クリックできます。すべての方法はマウスなしで右クリックする方法にまとめています。

トラックパッドが動かなくなりました。トラックパッドなしでBluetoothをオンにするには？

Appleが紹介している方法です。Command-Spaceを押して「Bluetoothファイル交換」と入力し、Returnを押します。続けてもう一度Returnを押すとBluetoothがオンになります。そのほかの対処法はMacのトラックパッドが動かないときの対処法をご覧ください。

Macでキーボードからボタンをクリックする無料の方法はありますか？

あります。フルキーボードアクセスは標準機能で無料です。音声コントロールの「Show numbers」は画面上の項目にラベルを付け、声でクリックできるようにします。Scootのような無料のオープンソースアプリもあります。Mac向けキーボードマウスアプリのおすすめで有料アプリと比較しています。

No Mouse Modeに無料体験版はありますか？

ありません。Mac 1台につき$19.99の買い切りで、アップデートは無料、サブスクリプションはありません。ウェブサイトには同じキーを使うインタラクティブなデモがあるので、購入する前に使い心地を試せます。

No Mouse ModeはどのバージョンのmacOSで使えますか？

macOS 14 Sonoma以降（SequoiaとTahoeを含む）で、Appleシリコン搭載MacとIntel Macの両方に対応しています。
