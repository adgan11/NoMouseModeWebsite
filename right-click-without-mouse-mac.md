# How to right-click on a Mac without a mouse

Source: https://nomousemode.com/right-click-without-mouse-mac  
Updated: 2026-10-31 · Author: Ahmed Gagan (maker of No Mouse Mode)

**With a trackpad, hold Control and click.** With no pointer at all, use Alternate pointer actions, Voice Control, the Contextual Menu key on some Apple keyboards, or No Mouse Mode, where Return right-clicks.

> **Short answer:** Apple calls a right-click a **secondary click or Control-click**. If your trackpad works, **hold Control and click**. With no working pointer, macOS offers **Alternate pointer actions** (keyboard shortcuts for right-click) and **Voice Control**, and some Apple keyboards have a **Contextual Menu key**. Mouse Keys alone has no right-click key. In [No Mouse Mode](https://nomousemode.com/), **Return** right-clicks where the pointer is, and **⇧ with a label's last letter** right-clicks that button.

## 1. Control-click (needs a trackpad or mouse)

The classic. Hold `Control` and click with the trackpad or mouse, and the shortcut menu opens. It's the right answer if your trackpad works but you don't have a two-button mouse.

### Change how the trackpad right-clicks

Open System Settings → **Trackpad** (or **Mouse**) and use the **Secondary click** pop-up menu to choose how a right-click works on that device. If clicks aren't registering at all, see [what to do when your Mac trackpad isn't working](https://nomousemode.com/mac-trackpad-not-working).

## 2. The Contextual Menu key

On the **Magic Keyboard with Touch ID and Numeric Keypad (USB-C)**, the Contextual Menu key, below F13, opens a shortcut menu. It's the closest thing to a dedicated right-click key on an Apple keyboard.

## 3. Alternate pointer actions (built in, keyboard only)

Mouse Keys moves the pointer with `7` `8` `9` `U` `O` `J` `K` `L` and clicks with `I`, but Apple's Mouse Keys page lists no right-click key. For that, turn on **Alternate pointer actions**:

1. Open System Settings → **Accessibility → Pointer Control**.
2. Turn on **Alternate pointer actions**.
3. Assign a keyboard shortcut to right-click. It also covers left-click, double-click and drag and drop, and can use switches or facial expressions instead of keys.

Pair it with Mouse Keys to get the pointer where you want it first. Remember that Mouse Keys blocks typing while it's on. More on that in [how to move the mouse with the keyboard](https://nomousemode.com/move-mouse-with-keyboard-mac).

## 4. Voice Control

Turn on System Settings → Accessibility → **Voice Control**. Say "Show numbers" to label what's on screen, then say a command with the item's number. Apple's [Voice Control commands](https://support.apple.com/guide/mac-help/use-voice-control-commands-mh40719/mac) page lists them. For spots without a label, "Show grid" puts a numbered grid over the screen and saying a number zooms in. "Hide numbers" and "Hide grid" put them away.

## 5. No Mouse Mode: right-click from the keyboard

[No Mouse Mode](https://nomousemode.com/) gives you right-click in every one of its modes, so you never have to set it up separately.

- **At the pointer:** press `⇧⌘M` to turn it on, move with `W` `A` `S` `D`, and press `Return` to right-click.
- **On a button:** press `⇧⌘Space` for click labels, then hold `⇧` while typing the label's last letter. The button is right-clicked without moving the pointer by hand.
- **By name:** press `⇧⌘/`, type part of the button's or text's name, and press `⇧Return`.
- **Anywhere on screen:** press `E` for the jump grid, pick cells until you're on target, then press Return.

When the menu opens, the arrow keys and Return pick an item. Labels depend on apps describing their buttons to macOS, which most do. The jump grid and W A S D work in any app.

## Which one should you use?

- **Trackpad works, no second button:** Control-click. Nothing to set up.
- **Trackpad or mouse is dead right now:** Alternate pointer actions with Mouse Keys, or Voice Control. Both are free and built in. If your Bluetooth mouse simply dropped, Apple's tip is to press `⌘Space`, type Bluetooth File Exchange, press Return, then Return again to turn Bluetooth on. More fixes in [Mac trackpad not working](https://nomousemode.com/mac-trackpad-not-working).
- **You right-click many times a day without touching the trackpad:** a keyboard app saves the most time, because the right-click is one key and you can aim at a button by its label instead of steering.

## Other clicks you'll need

Right-click is rarely the only thing a trackpad does for you. Here's how the same tools handle the rest.

- **Double-click:** Alternate pointer actions has a double-click action. In No Mouse Mode, press Space twice, or hold `⌥` with a label's last letter.
- **Drag:** in Mouse Keys, `M` presses and holds and `.` releases. In No Mouse Mode, hold Space and move with W A S D.
- **Command-click (new tab):** in No Mouse Mode, hold `⌘` with a label's last letter.
- **Middle click and back / forward:** No Mouse Mode uses `M`, `[` and `]`.

Every No Mouse Mode key can be remapped in Settings if Return doesn't suit you as the right-click key.

## FAQ

### What is the keyboard shortcut for right-click on a Mac?

macOS has no single right-click key on most keyboards. Holding Control while you click does it with a trackpad or mouse. The Magic Keyboard with Touch ID and Numeric Keypad (USB-C) has a Contextual Menu key. For a keyboard shortcut you set up yourself, turn on Alternate pointer actions in System Settings → Accessibility → Pointer Control. In [No Mouse Mode](https://nomousemode.com/), Return right-clicks.

### How do I right-click on a MacBook trackpad?

Hold Control and click. To choose how secondary click works on the trackpad itself, open System Settings → Trackpad and use the Secondary click pop-up menu.

### Can Mouse Keys right-click?

Apple's Mouse Keys page lists no right-click key. Its keys are I to click, M to press and hold, and the period to release. For right-click, turn on Alternate pointer actions in the same Pointer Control settings.

### How do I right-click with Voice Control?

Turn on Voice Control in System Settings → Accessibility → Voice Control, say "Show numbers" to label what's on screen, then give a command for the numbered item. Apple's Voice Control command list has the full set.

### How do I right-click a specific button without moving the pointer?

In [No Mouse Mode](https://nomousemode.com/), press Shift-Command-Space to show click labels, then hold Shift while you type the label's last letter. In type to click (Shift-Command-/), Shift-Return right-clicks the match.
