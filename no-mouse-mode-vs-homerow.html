Homerow vs No Mouse Mode: which keyboard-clicking app fits you?

Both put letter labels on buttons so you can click with the keyboard. Homerow focuses on labels, search and scrolling; No Mouse Mode adds a full keyboard mouse on top, for less money on one Mac.

Updated October 2026 · 7 min read · by Ahmed Gagan, maker of No Mouse Mode

Short answer

Homerow is a polished, actively maintained app that labels buttons so you can click them by typing, with search and scrolling too. It costs $49.99 once for all your personal Macs and is free to try. No Mouse Mode does click labels, type to click and scroll areas as well, then adds a full keyboard mouse: smooth W A S D movement, every mouse button, a jump grid, saved spots and display jumps. It's $19.99 for one Mac, with no trial but live demos on the site. If you only need labels across several Macs, Homerow is a fair pick. If you want to drop the mouse completely on one or two Macs, No Mouse Mode does more for less.

Get No Mouse Mode

What Homerow does well

Homerow describes itself as "keyboard shortcuts for every button in macOS". You press a shortcut, small labels appear on the buttons, links and other controls on screen, and you type a label to click it. Its site shows three main features: labels, search and scroll.

  • It's mature. Homerow is the successor of Vimac, the free open-source keyboard navigation app. Vimac's README calls Homerow "a refined, sleeker, more performant successor".
  • It's maintained. The latest version is 1.5.3, released March 19, 2026, and version 1.1.0 added extra scroll-mode commands.
  • The license is generous. One $49.99 purchase covers all your personal Macs and all future updates, as of October 2026. There's also a student discount.
  • You can try it first. Homerow is free to try, with a reminder every 50 activations.
  • It runs on older macOS. It needs macOS 13 or later.

Homerow says it works with "most native macOS apps and a growing set of non-native web-based apps". That's the honest limit of every label app: labels only appear where an app tells macOS about its buttons.

What No Mouse Mode does differently

No Mouse Mode starts from the same idea, then tries to replace the mouse entirely. It has three shortcuts that work anywhere: ⇧⌘Space for click labels, ⇧⌘/ for type to click and ⇧⌘J for scroll areas. Press ⇧⌘M to turn on No Mouse Mode itself, and the keyboard becomes a mouse.

Click labels and type to click

Every button, link, tab, menu, the menu bar and the Dock get letter labels. Hold Shift with the last letter to right-click, Command for a Command-click (new tab), Option to double-click, or Control to just move the pointer there. Press Tab to keep labels open for several clicks in a row. Labels for a window stay the same each time, so you build muscle memory. Type to click lets you type part of a button's name instead (initials work), then press Return.

A real keyboard mouse

With No Mouse Mode on, W A S D move the pointer smoothly, easing in. Hold Shift to go fast or Q for one-pixel precision. Space clicks (twice to double-click, hold to drag), Return right-clicks, M middle-clicks and [ / ] are back and forward. The arrow keys scroll in every direction. This is the part that matters when a control has no label, or when you need to drag, select text or draw.

Getting anywhere fast

Press E for the jump grid: a 3×3 grid labelled Q W E / A S D / Z X C that zooms in with each press, so two or three presses reach any spot on screen. Save spots with Shift+1–9 and jump back to them with 1–9, press ` to jump back, and use Tab / Shift+Tab to move between displays.

Help for apps that don't cooperate

An optional mode reads on-screen text with Apple's on-device text recognition, so apps that don't describe their buttons to macOS can still get labels. It needs Screen Recording permission, and nothing is saved or sent. Turn it off and No Mouse Mode needs only Accessibility.

Built to be learned

A guided first-run setup, a Practice window with nine hands-on lessons, and H to show every key. Every key and shortcut can be remapped.

Price and trial, plainly

As of October 2026, Homerow is $49.99 once and covers all your personal Macs. No Mouse Mode is $19.99 once for one Mac, $49.99 for three, $79.99 for five and $299.99 for twenty. Neither is a subscription, and both include updates.

  • One Mac: No Mouse Mode costs $30 less.
  • Three Macs: the same price.
  • Four or more personal Macs: Homerow is cheaper.

The try-before-you-buy story is different too. Homerow lets you use the real app for free, with a reminder every 50 activations. No Mouse Mode has no free trial, and all sales are final. What it offers instead is the live demo on this page and on the homepage: they run in your browser and use the same keys as the app, so you can feel the labels, the grid and W A S D movement before you pay.

The shared limit: apps have to describe their buttons

Both apps find buttons through macOS accessibility information. Most Mac apps and websites provide it. Some apps don't, and there labels may be missing or incomplete. No Mouse Mode's answer is the optional text recognition mode, the jump grid and W A S D movement, which work everywhere because they don't need to know what's on screen. If you mostly live in well-behaved apps, this difference may never come up.

Who should pick which

Pick Homerow if…

  • you mainly want to click buttons and links by typing, and you're happy using a mouse or trackpad for everything else;
  • you use four or more personal Macs and want one license for all of them;
  • you want to try the real app for a while before you pay;
  • you're on macOS 13 Ventura.

Pick No Mouse Mode if…

  • you want to stop reaching for the mouse altogether, including dragging, right-clicking and precise pointing;
  • you hit apps where labels don't show up and want a grid or pointer that always works;
  • you use one or two Macs and want the lower price;
  • you'd like practice lessons to get fluent quickly, for example if you're cutting back on the mouse because of wrist pain or your trackpad has stopped working.

Already using a free option? Apple's built-in tools may be enough for light use. See No Mouse Mode vs Mouse Keys, or the full list of Homerow alternatives, including Shortcat, Wooshy, Scoot and Mouseless.

Can you run both?

You can, but there's little reason to: their label, search and scroll shortcuts look alike. If you do, remap No Mouse Mode's shortcuts in its settings so they don't overlap. FAQ

Is Homerow worth it?

If you want click labels, search and scrolling and you use several Macs, Homerow is a well-maintained choice. As of October 2026 it costs $49.99 once, covers all your personal Macs and includes future updates. It's free to try, with a reminder every 50 activations, so you can find out for yourself.

Is No Mouse Mode cheaper than Homerow?

For one Mac, yes: $19.99 versus $49.99 (as of October 2026). No Mouse Mode's 3-Mac license is $49.99, the same as Homerow. For four or more Macs, Homerow's single price is cheaper, because it covers all your personal Macs. See No Mouse Mode pricing.

Does No Mouse Mode have a free trial like Homerow?

No. No Mouse Mode has no free trial and all sales are final. Instead, the website has interactive in-browser demos that use the same keys as the app, so you can try the feel before buying. Homerow is free to try, with a reminder every 50 activations.

Do Homerow and No Mouse Mode use the same shortcuts?

They look similar. Homerow's website demos show ⌘⇧Space for labels, ⌘⇧J for scroll and ⌘⇧/ for search. No Mouse Mode's defaults are ⇧⌘Space (click labels), ⇧⌘J (scroll areas) and ⇧⌘/ (type to click). Every No Mouse Mode shortcut can be remapped, so you can change them if you run both.

Which one works in more apps?

Both rely on apps describing their buttons to macOS. Homerow says it works with most native macOS apps and a growing set of web-based apps. No Mouse Mode has an optional on-device text recognition mode for apps that don't describe their buttons, plus a jump grid and W A S D movement that work in any app.

Is Homerow the same as Vimac?

Homerow is Vimac's successor. Vimac's README says "Vimac is now Homerow". The open-source Vimac hasn't been updated since 2022. If you're still on it, see Vimac alternatives.

What macOS versions do they need?

Homerow needs macOS 13 or later. No Mouse Mode needs macOS 14 Sonoma or later and runs on Apple silicon and Intel Macs.
