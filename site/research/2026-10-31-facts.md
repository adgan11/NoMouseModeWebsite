## No Mouse Mode (our product): the only claims pages may make about it
Copied from /NoMouseMode-Website/llms.txt (2.0.1). Keep it in sync with llms.txt.
- macOS menu bar app that turns the keyboard into a mouse. Version 2.0.1.
- Platform: macOS 14.0 Sonoma or later, including Sequoia and Tahoe; Apple silicon and Intel.
- Price: one-time purchase (no subscription), free updates. $19.99 for 1 Mac, $49.99 for
  3 Macs, $79.99 for 5 Macs, $299.99 for 20 Macs. Buy: https://nomousemode.com/buy
  (/buy/3, /buy/5, /buy/20). Store: Dodo Payments (merchant of record). Version-1 sales
  were on Gumroad.
- **No free trial.** The website has interactive in-browser demos that use the same keys.
  Terms say all sales are final, no refunds. Never claim a trial, refund or money-back
  guarantee.
- Licensing: activated with the license key from the purchase. Version-1 buyers download
  2.0 from https://nomousemode.com/download and it unlocks itself on the Mac already in
  use. For a new Mac they email support.
- Global shortcuts (work with No Mouse Mode on or off): Click labels ⇧⌘Space; Type to
  click ⇧⌘/; Scroll areas ⇧⌘J; turn No Mouse Mode on/off ⇧⌘M (or hold Right Command /
  Right Option, optional).
- Keys while on: W A S D move (smooth, eases in); hold Shift = fast, hold Q = precise;
  Space = left click (twice = double, three times = triple, hold = drag); Return = right
  click; M = middle click; [ / ] = back / forward; arrow keys = scroll; F = click labels;
  / = type to click; J = scroll areas; E = jump grid; Tab / Shift+Tab = next / previous
  display; 1–9 jump to saved spot, Shift+1–9 save; ` = jump back; H = show all keys.
- Every key and shortcut can be remapped. Shortcuts that use Command, Control or Option
  always reach the focused app.
- Click labels: every button, link, tab, menu, the menu bar and the Dock get letter
  labels; type one to click it. Hold Shift (right-click), Command (Command-click / new
  tab), Option (double-click) or Control (just move) with the last letter. Tab keeps labels
  open for several clicks. Labels for a window stay the same each time.
- Type to click: type part of a button's or text's name (case, spaces and accents
  ignored; initials work); Return clicks.
- Labels in every app (optional): reads on-screen text with Apple's on-device text
  recognition for apps that don't describe their buttons to macOS. Needs Screen Recording
  permission; nothing is saved or sent.
- Smooth movement with fast and one-pixel precise modes. All buttons: click, double,
  triple, drag, right, middle, back, forward.
- Scrolling: smooth arrow-key scrolling in every direction. Scroll areas number each pane;
  then Space pages, T/B jump to top/bottom, J/K scroll.
- Jump grid (E): 3×3 grid labelled Q W E / A S D / Z X C, zooms in with each press; 2–3
  presses reach anywhere; works in any app.
- Saved spots, jump back, display jumps.
- Stays out of the way: turns itself off in apps you list and when you click into a text box.
- Easy to learn: guided first-run setup, a Practice window with nine hands-on lessons,
  H shows every key. Optional hold-to-use, label colors and sizes, launch at login, automatic updates.
- Private: keystrokes are never stored or sent. Goes online only to activate/re-check the
  license and to check for updates.
- Permissions: Accessibility; Screen Recording only if on-screen text reading is turned on.
- Support https://nomousemode.com/support · Privacy /privacy · Terms /terms.
- **Shortcut overlap (careful):** Homerow's site demos show ⇧⌘Space / ⇧⌘J / ⇧⌘/, and
  Shortcat's default is ⇧⌘Space (sections below). Never call our default shortcuts unique.
  Don't claim they clash for users either, since Homerow's are inferred from demo labels.

## Shortcat  (https://shortcat.app)
- "The universal command palette for your Mac." It indexes the UI; you type what you want
  to click ("ok" for an OK button). Supports clicking, right clicking, double clicking,
  clicking with modifiers; window search; menu search; emoji mode. Works in Safari, Chrome,
  Firefox and some Chromium browsers; most Electron apps. "Effectiveness may vary depending
  on application's Accessibility implementation."
- **Default activation: Cmd + Shift + Space** (docs Getting Started). After 2 seconds
  (configurable) it shows black-on-yellow labels with 1–3 letter shortcuts.
- Requirement: macOS 13+, Apple silicon / Intel; "tested on 15.3".
- **Latest v0.12.2, July 3, 2025.** v0.12.1 (July 1, 2025) "Bump beta expiry to 2030".
  Before that, v0.12.0 (April 2, 2025) and v0.11.4 (January 31, 2023). It is still a
  0.x beta with a beta-expiry date. Changelog history: "Work has stalled" (2018), "Work
  has resumed" (2017), "Looking for experienced Mac devs/group to partner" (2020).
- Price: **the official site states no price.** It is a free download (also
  `brew install shortcat`). Changelog v0.5.0 (2013) "Added licensing!" with a buy link.
  Do not say "free forever" or quote a price.
- Maintenance: no release in the ~16 months since July 2025. Say "last updated July 2025".
  Don't call it dead.
- Trademark: "Shortcat® is a registered trademark of Chendo Enterprises Pty Ltd, under
  license to Sproutcube."
- Sources: https://shortcat.app/ , https://shortcat.app/changelog-raw ,
  https://shortcat.app/docs/getting-started/

## Scoot  (https://github.com/mjrusso/scoot)
- "Keyboard-driven MacOS cursor actuator": move, click, drag, scroll. Free, open source,
  BSD-3-Clause. ~535 stars. **Latest v1.3 (2026-03-02)**, so maintained.
- Three modes, defaults: ⇧⌘J element-based (labels on buttons/links in the focused window
  via Accessibility); ⇧⌘K grid-based (equal cells across connected screens, each with a
  key sequence); ⇧⌘L freestyle (no overlay; nudge the cursor with macOS, Emacs or vi text
  shortcuts). All shortcuts customizable.
- README says it "runs on MacOS 11 (Big Sur), and 12 (Monterey)". Newer versions are not
  stated, so don't claim them either way. `brew install --cask scoot`.
- Note: Scoot's ⇧⌘J default equals our Scroll areas shortcut.

## Mouseless  (https://mouseless.click, by "cymian" / Sonuscape)
- "Lightning-fast mouse control with the keyboard." Cross-platform: macOS, Windows, Linux.
- Pricing: "Lifetime or subscription"; **amounts are not published on the site (unknown).**
  "14-day trial, no card/email". "Each license can be activated on 5 machines." 25% academic
  discount. Do not quote $10 (that comes from an old third-party listing).
- How it works (docs): grid mode. Tap Left Command (Mac) to show the overlay, type a cell's
  two characters, then Space clicks its center or a subgrid key clicks a sub-cell. Free
  mode: tap Left Option; I/J/K/L move; hold S/D/F faster, A slower. Clicks: Space left,
  R right, E middle, Q back, W forward. Scroll in free mode: M / , up/down, . / / left/right.
  Drag: hold Left Command with a click key. Label mode is **beta** (Shift + Left Command).
- Homebrew cask: v1.1.0, macOS >= 12. GitHub cymian/mouseless is a bug tracker (not the
  source code): v1.1.0 released 2026-10-26, ~734 stars. Actively maintained. Closed source.

## warpd  (https://github.com/rvaiya/warpd)
- "A modal keyboard-driven virtual pointer." Free, open source, MIT. ~3,660 stars.
- Modes (defaults; A-M = Alt+Meta, Meta = Command on macOS): Hint `A-M-x` (shows hints;
  type one to warp the pointer there); Grid `A-M-g` (u/i/j/k pick quadrants repeatedly;
  m left, `,` middle, `.` right click); Normal `A-M-c` (hjkl move; m/,/. click; v drag;
  Esc quits). README says hints are screen positions. It does not say they come from UI
  elements.
- Runs on X11, Wayland (sway/wlroots only) and macOS. The macOS install is a prebuilt
  v1.3.5 tarball + launchctl, or a source build with the Xcode CLT. README notes:
  pointer-hiding hack doesn't work in some programs (e.g. iTerm); upgrading may need
  `sudo tccutil reset Accessibility`.
- **Maintenance: last commit 2023-06-03; last macOS release v1.3.5 (2022-11-05)**; last
  release overall v1.3.7-windows-alpha (2023-04-26). 90 open issues. Not archived. Say
  "not updated since 2023". Minimum macOS: unknown.

## Browser-only link-hint extensions (they work inside web pages, not in Mac apps)
- **Vimium** (https://github.com/philc/vimium): "a browser extension that provides
  keyboard-based navigation and control of the web". Chrome, Edge, Firefox (Safari not
  listed). `f` link hints in the current tab, `F` new tab. MIT, ~27.1k stars, last commit
  2026-07-25 (active).
- **Vimium C** (https://github.com/gdh1995/vimium-c): keyboard navigation + tab operations
  with an omnibar. Chrome/Chromium 102+ (incl. Edge), Firefox 101+. `f`/`F` hints for
  links and buttons. Apache-2.0 (LICENSE.txt). ~4.6k stars; last commit on default branch
  2025-04-14; last GitHub release v1.99.995 (2023-04-10).
- **Vimari** (https://github.com/televator-apps/vimari): "Safari extension that provides
  vim style keyboard based navigation", a port of Vimium. Free on the Mac App Store
  (v2.1.1, last App Store update 2021-01-27); last commit 2021-04-12. **Unmaintained since
  2021** (not archived). `f` / `F` hints.
- **Vimlike** (App Store id1584519802, seller Minwoo Lee): Safari extension. "j and k
  scroll, f labels every link", ⇧F background tab. **Free: "No in-app purchases, no
  account, no tracking."** iPhone, iPad, Mac, Apple Vision Pro. v2.0.1, updated 2026-10-24
  (active).
- Key point for pages: these only label links inside the browser page. They don't reach
  Finder, System Settings, the menu bar, the Dock or other apps.

## macOS built-ins (Apple Support)
### Mouse Keys
- Path: Apple menu > System Settings > Accessibility > Pointer Control > Mouse Keys
  (same in the Sequoia 15, Tahoe 26 and macOS 27 guides). "You can also use Accessibility
  Shortcuts to quickly turn Mouse Keys on or off." **Option-Command-F5** (or triple-press
  Touch ID) shows the Accessibility Shortcuts panel.
- Keys. Move: keypad 7 8 9 4 6 1 2 3, or keyboard **7 8 9 U O J K L**. Click: keypad 5 or
  **I**. Press and hold: keypad 0 or **M**. Release: keypad "." or "." (period).
- **"When Mouse Keys is on, you can't use the keyboard or numeric keypad to enter text."**
- Options (click the info button next to Mouse Keys): "Press the Option key five times to
  toggle Mouse Keys"; "Ignore built-in trackpad when Mouse Keys is on"; Initial delay;
  Maximum speed.
- Apple's Mouse Keys page lists no dedicated right-click key. For left, right or double
  clicks via keyboard shortcuts, switches or facial expressions, turn on "Alternate pointer
  actions" (same Pointer Control pane: left-click, right-click, double-click,
  drag-and-drop).
- Sources: https://support.apple.com/guide/mac-help/use-your-keyboard-like-a-mouse-mh27469/mac ,
  https://support.apple.com/guide/mac-help/change-pointer-control-settings-accessibility-unac899/mac ,
  https://support.apple.com/en-us/102650

### Full Keyboard Access
- Highlights the focused item and lets you navigate with the keyboard instead of a mouse
  or trackpad. You can customize the highlight's color, contrast and size.
- Turn on: System Settings > Accessibility > **Motor > Keyboard** > Full Keyboard Access
  (Tahoe 26 and macOS 27 guides).
- Keys: Tab / Shift-Tab next/previous element; Space selects; arrows move within a group;
  Control-Tab / Control-Shift-Tab next/previous item; **Tab-H opens Commands Help**;
  Control-Option-Command-P toggles Pass-Through Mode.
- Source: https://support.apple.com/guide/mac-help/use-full-keyboard-access-mchlc06d1059/mac

### Keyboard navigation (Tab between controls)
- Sonoma 14 guide: System Settings > Keyboard > turn on "Keyboard navigation". Tab moves
  to the next control, Shift-Tab to the previous one. Turned off, Tab moves only between
  text boxes and lists. (Page not in the 15+ guides.)
  https://support.apple.com/guide/mac-help/use-your-keyboard-like-a-mouse-mchlp1399/14.0/mac/14.0
- Shortcut (current shortcuts page): **Control-F7** (or Fn-Control-F7) switches Tab between
  all controls and only text boxes and lists.

### Focus shortcuts (https://support.apple.com/en-us/102650)
- Some must first be enabled: System Settings > Keyboard > Keyboard Shortcuts > Keyboard.
- **Control-F2** (or Fn-Control-F2): focus the menu bar, then arrows to navigate, Return
  to open/choose, or type an item's name. **Control-F3**: Dock. Control-F4: active/next
  window. Control-F5: window toolbar. Control-F8: status menu in the menu bar.
  (Control-F1 is not listed on the current page; don't mention it.)

### Voice Control
- Settings: System Settings > Accessibility > Voice Control.
- "Show numbers" / "Show names" label on-screen items. Say "Click" plus the number or
  name. "Hide numbers" / "Hide names" removes them. "Show grid" shows a numbered grid,
  "Show window grid" limits it to the active window, saying a grid number refines it, and
  "Hide grid" removes it. "Stop listening" / "Start listening" pause and resume.
- Source: https://support.apple.com/guide/mac-help/use-voice-control-commands-mh40719/mac

### Accessibility Keyboard / Dwell
- On-screen keyboard to use the Mac without a physical keyboard. Path: System Settings >
  Accessibility > Keyboard > Accessibility Keyboard. Dwell (Panel Options button) "lets you
  perform mouse actions using eye- or head-tracking technology." Head pointer exists
  (Accessibility > Mobility). It is not a keyboard-to-pointer tool.
- Source: https://support.apple.com/guide/mac-help/use-the-accessibility-keyboard-mchlc74c1c9f/mac

### Right-click without a mouse
- Apple: a right-click is "a secondary click or Control-click". Hold **Control** while you
  click with a mouse or trackpad. The trackpad/mouse "Secondary click" pop-up is in System
  Settings > Trackpad / Mouse. On a Magic Keyboard with Touch ID and Numeric Keypad
  (USB-C), the **Contextual Menu key** (below F13) opens a shortcut menu.
  https://support.apple.com/en-au/guide/mac-help/right-click-mh35853/mac
- Fully keyboard-only, built in: Alternate pointer actions (above) or Voice Control
  ("Show numbers", then a command on the item). Apple's Mouse Keys page itself has no
  right-click key.

### When the trackpad/mouse stops working (https://support.apple.com/en-us/102498)
- Turn the device off and on (switch shows green when on). Make sure Bluetooth is on in
  System Settings. If it won't turn on, restart. Connect by cable for 1 minute, then
  unplug (pairs and charges). Interference can cause drops.
- **No mouse:** "press Command-Space bar", type "Bluetooth File Exchange", press Return,
  then Return again to turn Bluetooth on.
- Mouse Keys and Full Keyboard Access (above) work with no pointer device at all.
