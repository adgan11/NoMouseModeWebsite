简短回答

先从内置功能开始：全键盘控制（Tab 在控件间移动，Space 按下），再加上 Control-F2 跳到菜单栏、Control-F3 跳到程序坞。日常工作的很多场景都能应付。它的短板在于需要指针的操作：网页、画布、右键点按、拖移。鼠标键可以免费补上这块，但开启期间无法打字。如果你想几下按键就点到任何按钮，还能平滑地操控指针，No Mouse Mode 这样的 App 两样都能做到。

为什么要摆脱鼠标？

来到这里的原因各不相同。触控板或鼠标刚好坏了，你得先撑过今天；长时间工作后手腕疼；或者你本来就整天在代码编辑器里用键盘，伸手去摸触控板会打断思路。好消息是：macOS 在设计时就考虑到了键盘用户，它留下的空缺也很容易补上。

如果你的触控板此刻就不能用了，直接看Mac 触控板失灵怎么办。如果是为了舒适，请看手腕疼痛时只用键盘操作 Mac。

内置功能：全键盘控制与键盘导航

全键盘控制会高亮显示当前获得焦点的项目，让你用键盘而不是指针四处移动。你可以更改高亮的颜色、对比度和大小，在内容繁杂的屏幕上很有帮助。

  1. 打开“系统设置”→“辅助功能”→“运动”→“键盘”。
  2. 打开全键盘控制。

按键：

  • Tab / ⇧Tab：下一个或上一个元素。
  • Space：选择或按下获得焦点的项目。
  • 箭头键：在一组内移动。
  • ⌃Tab / ⌃⇧Tab：下一个或上一个项目。
  • Tab-H：打开“命令帮助”，列出其他所有操作。
  • ⌃⌥⌘P：直通模式，适用于需要自己使用这些按键的 App。

在 macOS 14 Sonoma 上，“系统设置”→“键盘”中还有一个更轻量的设置，叫键盘导航。打开后，Tab 会移到每个控件；关闭时，Tab 只在文本框和列表之间移动。⌃F7 可以在两者之间切换。我们的全键盘控制指南讲得更深入。

缺点：Tab 是按顺序一个一个地访问控件。要到达工具栏上的第二十个按钮，就得按很多次；而且很多网页和自绘界面的 App 对它的支持也不好。

内置功能：焦点快捷键

这些快捷键可以直接跳到 Tab 不容易到达的屏幕区域。有些需要先在“系统设置”→“键盘”→“键盘快捷键”→“键盘”中打开。在某些键盘上还要加按 Fn（例如 Fn-Control-F2）。

内置功能：鼠标键

鼠标键会把键盘的一部分变成指针。在“系统设置”→“辅助功能”→“指针控制”→“鼠标键”中打开，或按 ⌥⌘F5 打开“辅助功能快捷键”面板。然后：

  • 移动：7 8 9 U O J K L（或数字小键盘）。
  • 点按：I（小键盘 5）。
  • 按住：M（小键盘 0）；松开：.

它完全不需要任何指针设备，而且免费。最大的限制，用 Apple 的原话说：“鼠标键打开时，你无法使用键盘或数字小键盘输入文本。”所以你得不停地开关它。它有一个选项，可以连按五次 Option 键来开关。我们在 No Mouse Mode 与鼠标键对比中做了正面比较，细节见如何用键盘移动鼠标。

内置功能：语音控制

如果你更愿意说而不是打字，请打开“系统设置”→“辅助功能”→“语音控制”。说“Show numbers”（或“Show names”），屏幕上的项目就会出现标签；说“Click”加上编号即可按下对应项目。“Show grid”会在屏幕上铺一层带编号的网格，“Show window grid”只覆盖最前面的窗口，说出网格编号就会放大。“Hide numbers”“Hide grid”和“Stop listening”用来收起它们。

它功能强大又免费，但一整天的工作每次点击都靠说话，速度很慢，在共享办公室里也很尴尬。

那 Control-点按呢？

Apple 把右键点按称为“辅助点按或 Control-点按”：按住 Control 再点按。但这仍然需要一个能用的鼠标或触控板。只用键盘的方法，包括部分 Apple 键盘上的上下文菜单键，请看如何不用鼠标右键点按。

No Mouse Mode：点击任何东西，需要时再操控指针

No Mouse Mode 是一款菜单栏 App，专门补上上面这些空缺。它提供两种工作方式，可以混着用。

点击标签（⇧⌘Space）

每个按钮、链接、标签页、菜单，以及菜单栏和程序坞，都会获得一个简短的字母标签。输入这些字母就会点击它。输入最后一个字母时按住 ⇧ 是右键点按，按住 ⌘ 是 Command-点按（在浏览器中打开新标签页），按住 ⌥ 是连按两次，按住 ⌃ 则只是把指针移过去。按 Tab 可以让标签持续出现，连续点击好几次；同一个窗口的标签每次都一样，手指会慢慢记住。

输入即点击（⇧⌘/）

输入按钮上文字的一部分，然后按 Return。大小写、空格和重音符号都不影响，首字母也行：“nf”就能找到 New Folder。

滚动区域（⇧⌘J）

每个可滚动的面板都会获得一个编号。选中一个后，用 J/K 或箭头键滚动，Space 翻页，T 和 B 跳到顶部或底部。

W A S D 指针模式（⇧⌘M）

对于不是按钮的东西，比如照片中的某个位置或一个滑块，打开 No Mouse Mode。W A S D 平滑地移动指针，起步时会缓缓加速；按住 Shift 快速移动，按住 Q 进行单像素的精确移动。Space 点按（按两次是连按两次，按住是拖移），Return 右键点按，M 中键点按，箭头键滚动。点进文本框时它会自动关闭，方便你打字。

跳转网格（E）

一个标着 Q W E / A S D / Z X C 的 3×3 网格覆盖整个屏幕，每按一次就放大一层，两三下按键就能到达任何位置。它在所有 App 中都能用，包括那些不向 macOS 描述自己按钮的 App。

坦白说的取舍：标签依赖 App 告诉 macOS 它们的按钮在哪里。大多数 App 都会这样做。对于不这样做的 App，你可以打开可选的屏幕文字识别（使用 Apple 的设备端文字识别，需要“录屏”权限；不会保存或发送任何内容），或者使用在任何地方都能用的网格和 W A S D。

5 分钟设置一台不用鼠标的 Mac

  1. 打开全键盘控制：在“系统设置”→“辅助功能”→“运动”→“键盘”中设置。现在 Tab 和 Space 能到达大多数控件。
  2. 记住 ⌃F2 和 ⌃F3，分别对应菜单栏和程序坞。如果按了没反应，请在“系统设置”→“键盘”→“键盘快捷键”→“键盘”中打开它们。
  3. 添加一种能点击任何东西的方式。下载 No Mouse Mode，拖到“应用程序”文件夹并打开。引导设置会带你完成辅助功能权限授权和许可证密钥输入。
  4. 用标签点击。按 ⇧⌘Space，输入你想点击的东西上的字母。
  5. 需要时操控指针。按 ⇧⌘M，用 W A S D 移动，Space 点按，Return 右键点按，按 E 打开网格。
  6. 练习。从菜单栏图标打开练习窗口，里面有九节简短的上手课程。忘了哪个键，随时按 H。

卡在某一步？支持页面介绍了权限、许可证和所有按键。

让纯键盘操作坚持下去的小技巧

第一天最难熬。下面几个习惯会有帮助：

  • 先用标签点击，再考虑操控指针。大部分点击都落在按钮、链接和菜单上。用标签或输入即点击，两三下按键就能搞定；W A S D 和网格留给其他情况。
  • 让它自动关闭。No Mouse Mode 在你点进文本框时会自动关闭；你还可以列出始终保持关闭的 App，比如游戏，或自带按键体系的代码编辑器。
  • 试试按住使用。如果觉得开关又多了一件要记的事，可以把它设置为只在按住右 Command 或右 Option 时生效。
  • 保存常用位置。在经常点击的位置上按 ⇧ 加一个数字，之后只按这个数字就能跳回那里。
  • 保留内置功能。用 ⌃F2 跳到菜单栏、用 ⌘Space 打开聚焦搜索（Spotlight），这些和其他方法可以同时使用。

关于隐私：No Mouse Mode 从不存储或发送你的按键记录。它只会在激活和重新验证许可证、以及检查更新时联网。

该用哪一种？

  • 触控板坏了一天：全键盘控制加鼠标键就能免费撑过去。
  • 更喜欢说话：语音控制。
  • 整天只用键盘，在所有 App 里：内置功能，再加一个能按标签点击并操控指针的 App。这正是 No Mouse Mode 的用途。查看价格。
