Short answer

warpd still has a macOS build, but it's old. The last Mac release is v1.3.5 from November 2022, the last commit was June 2023, and the README doesn't say which macOS versions it supports. If it runs for you, it's free and great. If it stops working, try resetting its Accessibility permission (below). If you'd rather have something maintained, No Mouse Mode covers all three warpd modes: hint mode becomes click labels, grid mode becomes the jump grid, and normal mode becomes W A S D movement. Scoot is a free option with a similar three-mode design.

What warpd does

warpd calls itself "a modal keyboard-driven virtual pointer". It's free and open source under the MIT license, with about 3,660 stars on GitHub, and it runs on X11, Wayland (sway/wlroots only) and macOS. It has three modes. In its docs, A-M means Alt+Meta, and Meta is Command on macOS, so A-M-x is ⌥⌘X.

  • Hint mode (⌥⌘X): shows hints on screen; type one and the pointer warps there.
  • Grid mode (⌥⌘G): pick quadrants over and over with u/i/j/k until you're on target; m, , and . click left, middle and right.
  • Normal mode (⌥⌘C): move with h j k l, click with m/,/., drag with v, quit with Esc.

On a Mac you install it from a prebuilt v1.3.5 tarball plus launchctl, or build it from source with the Xcode command line tools.

warpd not working? Things to try

  1. Check the Accessibility permission. Open System Settings > Privacy & Security > Accessibility and make sure warpd is switched on. Tools that move the pointer need this.
  2. Reset the permission after an upgrade. warpd's README says upgrading may need sudo tccutil reset Accessibility. Be aware this clears the whole Accessibility list, so you may have to re-allow other apps afterwards. Then allow warpd again.
  3. Expect the pointer-hiding quirk. The README notes that warpd's trick for hiding the pointer doesn't work in some programs, iTerm being the example. That's a known limitation, not a broken install.
  4. Check the open issues. With 90 open issues on GitHub, someone may already have hit your problem and posted a workaround.

If none of that helps, it may be time for something that's still being updated.

Hint mode → click labels

This is the biggest difference. warpd's README describes its hints as positions on the screen; it doesn't say they come from buttons. No Mouse Mode's labels are put on real buttons, links, tabs, menus, the menu bar and the Dock, using what apps tell macOS about themselves, so typing a label clicks that item. Hold ⇧ with the last letter to right-click, ⌘ to ⌘-click, ⌥ to double-click or ⌃ to just move the pointer there. The trade-off: apps that don't describe their buttons show few labels. For those you can turn on on-device text recognition (it needs Screen Recording permission; nothing is saved or sent), or use the grid.

Grid mode → jump grid

warpd splits into four quadrants per press; No Mouse Mode splits into nine, laid out like the Q–C block under your left hand, so two or three presses reach anywhere. Space clicks, Return right-clicks, Delete goes back a level and Tab moves the grid to the next display. Like warpd's grid, it works in any app because it doesn't need to know what's on screen. The keynav for Mac guide compares every keyboard grid on macOS.

Normal mode → W A S D

Instead of h j k l, movement defaults to W A S D, and it eases in so short taps are small and holding goes further. Shortcuts with ⌘, ⌃ or ⌥ still reach your apps while it's on. You also get back/forward buttons ([ / ]), saved spots (Shift+1–9 to save, 1–9 to jump) and ` to jump back. More in how to move the mouse with the keyboard on a Mac.

Other maintained options

  • Scoot (free, BSD-3, v1.3 in March 2026): the closest free match to warpd's shape, with element labels (⇧⌘J), a grid (⇧⌘K) and a freestyle mode that nudges the pointer with macOS, Emacs or vi keys (⇧⌘L). Its README says it runs on macOS 11 and 12 and doesn't mention newer versions.
  • Mouseless (closed source, 14-day trial, prices not published on its site, v1.1.0 in October 2026): a grid mode on Left Command and a free-movement mode on Left Option with I/J/K/L.
  • Homerow ($49.99 one time as of October 2026, macOS 13 or later): labels, scroll and search. See No Mouse Mode vs Homerow.
  • Mouse Keys (built in, free): fixed-pace pointer movement with 7 8 9 U O J K L. Compared in No Mouse Mode vs Mouse Keys.

Which should you use?

  • warpd still runs for you: keep it. It's free and does the job.
  • You want free and open source: try Scoot, checking it on your macOS version first.
  • You want all three modes plus type to click and scroll areas, maintained, with a guided setup: No Mouse Mode, $19.99 one time for 1 Mac (pricing), macOS 14 Sonoma or later on Apple silicon and Intel. No free trial, but the live demo on this page uses the same keys.
