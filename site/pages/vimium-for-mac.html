Short answer

Vimium can't leave the browser. It's a browser extension, so its f link hints only reach the web page in the current tab. The same goes for Vimium C, Vimari and Vimlike. To get the same "press a key, type the letters, it's clicked" feel in Finder, System Settings, the menu bar, the Dock and every other app, you need a Mac app that reads buttons through macOS accessibility. No Mouse Mode does that with ⇧⌘Space, and Homerow, Shortcat and Scoot are worth a look too. Keep Vimium in the browser if you love it; the two get along fine.

Why Vimium stops at the edge of the browser

Vimium describes itself as "a browser extension that provides keyboard-based navigation and control of the web". That last word is the limit. A browser extension can read and label the links in a web page because the browser hands it the page. It has no view of anything outside that page: not the browser's own toolbar, not Finder, not System Settings, not the menu bar or the Dock.

So when people search for "Vimium for Mac apps" or "Vimium outside the browser", what they actually want is a different kind of tool: a Mac app that asks macOS where every button is. macOS exposes that through its accessibility system, the same information screen readers use. An app with Accessibility permission can put a label on each button in the front window, the menu bar and the Dock, and click it when you type the label.

How the Mac-wide version feels

Click labels: the f you already know

Press ⇧⌘Space and every button, link, tab, menu, checkbox and field in the front window gets a short letter label, along with the menu bar and the Dock. Type the letters and it's clicked. This works whether No Mouse Mode is switched on or off. Labels for a window stay the same each time, so after a few days your fingers learn them, much like Vimium regulars learn their favourite hints.

Type to click: when you know the word, not the label

Press ⇧⌘/ and type what a button says. Case, spaces and accents are ignored, and initials work. Matches are outlined, Tab moves between them and Return clicks. It's the closest thing to searching your way to a link, but for the whole Mac. If this is the half you care about most, also read No Mouse Mode vs Shortcat, since Shortcat is built around exactly this.

Scroll areas: j and k for any pane

A Mac window often has several scrollable panes: a sidebar, a list, a preview. ⇧⌘J numbers each one. Pick one by number (or Tab), then scroll with J/K or the arrows, page with Space, and jump to the top or bottom with T and B. More on this in how to move the mouse with the keyboard on a Mac.

The honest catch

Vimium reads the web page itself. A Mac-wide app depends on each app describing its buttons to macOS. Most Mac apps and websites do. Some games, design canvases, remote desktops and older cross-platform apps don't, and they'll show few labels. For those, No Mouse Mode can optionally read the words on screen with Apple's on-device text recognition (it needs Screen Recording permission, and nothing is saved or sent). Buttons that are only icons still need the jump grid or W A S D, which work everywhere.

Other ways to get Vimium-style hints on the whole Mac

  • Homerow: "Keyboard shortcuts for every button in macOS". Labels, scroll and search. $49.99 one time as of October 2026, free to try with a reminder every 50 activations, macOS 13 or later. Actively maintained. Compared in No Mouse Mode vs Homerow.
  • Shortcat: "the universal command palette for your Mac". You type what you want to click; after a short pause it also shows letter labels. Free download, still a 0.x beta, last updated July 2025.
  • Vimac: the free, open-source app that became Homerow. Its Hint-mode is the most Vimium-like of the lot, but it hasn't been updated since 2022.
  • Scoot: free and open source, with element labels on ⇧⌘J, a grid mode and a freestyle mode. Its README says it runs on macOS 11 and 12 and doesn't state newer versions.
  • Voice Control (built into macOS): say "Show numbers", then "Click" and the number. It labels everything, but you speak instead of type.

Set it up in two minutes

  1. Download and open No Mouse Mode. Get it from the download page and drag it into Applications.
  2. Allow Accessibility. The first-run setup walks you through the one permission it needs and updates by itself when it's on.
  3. Try your new f. Open Finder and press ⇧⌘Space. Type the letters on a sidebar item.
  4. Try the extras. ⇧⌘/ to type a button's name, ⇧⌘J to scroll a pane. The Practice window has nine short lessons if you want a guided tour.

It needs macOS 14 Sonoma or later on Apple silicon or Intel, and costs $19.99 one time for 1 Mac (pricing). There's no free trial, but the live demo on this page uses the same keys. Questions go to support.
